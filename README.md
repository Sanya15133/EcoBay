# EcoBay

Overview

EcoBay is a web application built using Python and Django that allows members of a community to connect, share information, and support one another. The application provides a central platform where users can exchange items, offer and request skills, and share important notices and upcoming events.

The application encourages community engagement by allowing users to create posts, interact with listings, and manage the content they contribute.
Features
User Authentication

    User registration to create an account.
    User login to access the application.
    Authenticated access to relevant application features.

Items

    View items posted by other users.
    Create posts to list items.
    Bid on items posted by other users.
    Delete items or posts you have created.

Skills

    Add skills to share knowledge and abilities with the community.
    Request skills or assistance from other community members.
    View available skills and skill requests.

Notices

    Create and publish notices to share important community information.
    View notices posted by other users.
    Delete notices you have posted.

Events

    Create and publish community events.
    View events shared by other users.
    Delete events you have posted.

Content Management

    Manage your own contributions to the platform.
    Delete content you have posted when it is no longer needed.

Technologies Used

    Python — Core programming language.
    Django — Web framework used to develop the application.
    HTML and CSS — Used to structure and style the user interface.
    Django ORM — Used to interact with the database.
    Model Bakery — Used to generate model instances for testing.
    Django TestCase — Used to write and execute automated tests for models and views.
